# Day 18: Armstrong Number Checker

## 📌 Description
This Python program checks whether a given number is an Armstrong number.

An Armstrong number is a number equal to the sum of its digits, where each digit is raised to the power of the total number of digits.

### 💻 Example
**Input:**
```text
Enter number: 153
```

**Output:**
```text
Armstrong Number
```

### 🧠 Concepts Used
- User input using `input()`
- Type conversion using `int()` and `str()`
- `sum()` function
- List-free iteration over a string
- Exponentiation using `**`
- Conditional statements (`if-else`)

### ▶️ How to Run
1. Open the file in VS Code.
2. Run the Python program.
3. Enter an integer when prompted.
4. Check whether the number is an Armstrong number.

### 🎯 Learning Outcome
Learned how to convert a number into a string, process its digits, calculate powers, and use a condition to verify an Armstrong number.
